# MiniPay — Wallet API

Billetera virtual con dinero ficticio desarrollada para el Cuarto Proyecto Integrador.

## Features
- Registro y autenticación con JWT.
- Gestión de billetera virtual (depósitos y transferencias).
- Operaciones atómicas y manejo de concurrencia.
- Sistema de idempotencia para evitar transferencias duplicadas.

## Stack
- NestJS 11 + TypeScript
- Prisma ORM
- PostgreSQL
